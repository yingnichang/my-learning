# Learning-content format

## Detailed Study Guide

Build focused mini-lectures in source order. Use enough sections to preserve the full teaching sequence; a substantial lecture may require 30-40 sections.

Each mini-lecture should contain:

1. Title and concept category.
2. Source lecture and professor-PDF page range.
3. Observation: what the slide, chart, market fact, or empirical result shows.
4. Intuition: why it happens in plain language.
5. Mathematics or model structure: define every symbol and state what is held fixed.
6. Trading/modeling consequence: how the concept changes research, valuation, risk, or execution.
7. Common confusion: address likely misreadings, including the user's prior questions when relevant.
8. Memory rule: one compact sentence or formula.

Keep formulas faithful to the source and make notation consistent across lectures. When the transcript clarifies a slide, incorporate the clarification and label it as professor emphasis. Do not fabricate a quote.

## Lecture Notes

Each uploaded professor PDF receives one visually distinct section with:

- Explicit lecture number(s) and title.
- Professor name and page count when known.
- Clear statement when one file combines multiple lectures.
- Embedded viewer, Open PDF link, and Download link.
- Optional page jumps within the same PDF. Page jumps are navigation aids, not separate lecture sections.
- Outline derived from the actual file.

## Flashcards

Organize cards by lecture deck. Preserve the front, intuitive answer, and key formula or memory line.

For each update:

- Inventory existing cards by lecture.
- Search the current conversation and available project context for every card the user marked, accepted, or asked to save.
- Append new cards without removing existing concepts.
- Keep closely related cards separate when the distinction is pedagogically important, such as duration vs. DV01, zero vs. forward rates, z-spread definition vs. trading use, or beta vs. lambda.
- Update per-lecture counts and verify lecture switching resets progress cleanly.

Do not add every guide topic automatically. The Flashcards section represents material the user chose to memorize.
